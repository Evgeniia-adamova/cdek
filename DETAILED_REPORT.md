## 📁 СТРУКТУРА ФАЙЛОВ

### 🔧 ГЛАВНЫЙ МОДУЛЬ: `app/backend/calls_kpi_evaluation/`

#### 1. **kpi_analyzer.py** (950+ строк)
**Это главный двигатель модуля!**

Содержит:
- Класс `CallKPIAnalyzer` - основной анализатор
- Функция `analyze_call()` - анализирует текст
- 40+ методов для проверки каждого KPI критерия
- Расчет итоговой оценки (0-100 баллов)

Как это работает:
1. Берет текст транскрипции
2. Ищет в нем ключевые фразы (регулярные выражения)
3. Проверяет 40+ критериев
4. Считает баллы по 5 категориям
5. Возвращает JSON с результатом

Пример критериев которые проверяет:
- "Здравствуйте" / "добрый день" → приветствие ✓
- "меня зовут" → представление ✓
- "как вас зовут" → уточнение имени ✓
- "страховка" → страхование ✓
- И еще 36 критериев...

Результат:
```json
{
  "overall_score": 68,
  "score_percentage": 68.0%,
  "overall_status": "Удовлетворительно",
  "rating": "★★★"
}
```
