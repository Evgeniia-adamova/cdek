ОСНОВНЫЕ КОМАНДЫ ДЛЯ ЗАПУСКА KPI АНАЛИЗА
========================================

1. ИНТЕРАКТИВНЫЙ АНАЛИЗ (Самый простой)
   python run_kpi_analyzer.py
   
   Что это делает:
   - Запускает меню на выбор
   - Вставить текст вручную
   - Загрузить из файла
   - Запустить встроенные тесты

2. ПРОВЕРИТЬ ЧТО ВСЕ РАБОТАЕТ
   python verify_kpi_module.py
   
   Что это делает:
   - Проверяет все файлы
   - Проверяет импорты
   - Проверяет функциональность
   - Результат: ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ!

3. ЗАПУСТИТЬ ТЕСТЫ
   ./kpi.sh test
   
   Что это делает:
   - Анализирует хороший звонок  (68/100)
   - Анализирует плохой звонок   (8/100)

========================================
БЫСТРЫЕ BASH КОМАНДЫ
========================================

./kpi.sh verify          Проверить компоненты
./kpi.sh test            Запустить тесты
./kpi.sh run             Интерактивный анализатор
./kpi.sh example         Пример из JSON
./kpi.sh batch           Обработать пакет файлов
./kpi.sh results         Просмотреть результаты
./kpi.sh help            Справка
