## 🚀 КАК ИСПОЛЬЗОВАТЬ

### Вариант 1: Простой анализ текста

```python
from app.backend.calls_kpi_evaluation import analyze_call

# Анализируем любую транскрипцию
results = analyze_call("""
    Менеджер: Здравствуйте, меня зовут Иван
    Клиент: Привет
    ...
""")

# Результат:
print(f"Баллы: {results['overall_score']}/100")
print(f"Процент: {results['score_percentage']}%")
print(f"Статус: {results['overall_status']} {results['rating']}")
```

### Вариант 2: Интеграция в pipeline

Добавить в `app/run_full_pipeline.py` после step 3:

```python
from app.backend.calls_kpi_evaluation.pipeline_integration import add_kpi_to_pipeline_step4

# После combined_emotion_analysis
transcript = extracted_text  # Из step 3
kpi_results = add_kpi_to_pipeline_step4(transcript, video_id)

# Результаты автоматически сохранятся в data/kpi_analysis/
final_results = {
    'video_id': video_id,
    'emotion': combined_emotion_result,
    'kpi': kpi_results
}
```
